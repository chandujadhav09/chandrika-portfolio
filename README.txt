HOW TO RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension if it is not already installed.
4. Right-click index.html and select "Open with Live Server".
5. Use the navigation menu to visit all pages.

BEFORE PUBLISHING
1. Confirm the resume PDF is present in files/ChandrikaResume.pdf.
2. Replace the generic LinkedIn and GitHub links in contact.html with your real profile URLs.
3. Check that all personal details are correct.
4. The contact form currently performs browser-side validation only. It does not send or store messages.
5. jQuery and Google Fonts are loaded from CDNs, so those features need an internet connection.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository.
2. Upload the contents of this extracted folder (not the outer ZIP).
3. Ensure index.html is in the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.

ASSIGNMENT TECHNOLOGIES
